## 2024-05-18 - Missing Skip to Main Content Link
**Learning:** Found that this portfolio app, built with Next.js, lacks a 'skip to main content' link. This makes keyboard navigation very cumbersome as users have to tab through the navigation elements to get to the main page content on each reload or route change. Adding it enhances keyboard accessibility significantly.
**Action:** Added a 'skip to content' link that is visually hidden until focused, making it the first focusable element for screen readers and keyboard users.
