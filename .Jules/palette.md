## 2026-08-17 - Skip to Main Content Link Target Alignment
**Learning:** Adding a generic `id="main"` on the layout level is insufficient in a Next.js App Router context when different sub-routes (like `/blog` or `/reach`) utilize their own layout or page structures.
**Action:** Always ensure the `#main` target ID is applied specifically to the main container wrapper on each root page or layout file rather than assuming a single global implementation.
